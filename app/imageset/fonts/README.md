# Bundled fonts (image-set creative)

**Inter** — Regular, SemiBold, Bold — used to draw text onto generated creative
assets (e.g. the size-comparison header/footer bars) with Pillow, which needs a
TTF/OTF face it can rasterize.

These `.ttf` files are the same Inter faces the app already ships as web fonts in
`app/static/fonts/*.woff2` (the app's brand font), converted to TTF. Inter is the
font the source `marketplace-creative-studio` app uses for its creative text, so
DISCOtech's output matches it.
