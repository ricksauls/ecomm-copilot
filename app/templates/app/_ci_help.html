How setup works
  1. Add brands — mark your own as mine and rivals as competitor. (Brands come first — products attach to one.)
  2. Add products — paste each Walmart product URL and pick its brand. This is how results get attributed to the right brand.
  3. Add keywords — the search terms to track on Walmart.com.
  4. Run it — {% if group.mode == 'monitoring' %} Schedule & Run turns on the 3×/day checks (7 AM / 3 PM / 11 PM CST) and kicks off a baseline now. View results under View Monitoring. {% else %} Run snapshot scrapes once and shows the current-state results, which you can download as a PDF. {% endif %}

Search Ranking tracks where your products land; Share of Digital Shelf shows each brand's slice of page-1 slots (organic vs sponsored).
